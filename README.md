# Day 21 - Basic SQL SELECT

## Objective

To build basic SQL fundamentals by practicing SELECT, WHERE, and ORDER BY queries using MySQL.

## Tools Used

- MySQL Workbench
- MySQL

## Dataset

A sample employee dataset containing employee ID, name, department, salary, age, and city.

## Concepts Covered

- SELECT
- Selecting specific columns
- WHERE
- Comparison operators
- ORDER BY
- ASC sorting
- DESC sorting
- Combining WHERE and ORDER BY

## Queries Performed

1. Display all employees
2. Select employee names and departments
3. Find employees from IT
4. Find employees with salary above 50,000
5. Find employees from Kochi
6. Find employees younger than 28
7. Sort employees by salary in ascending order
8. Sort employees by salary in descending order
9. Filter IT employees and sort by salary
10. Sort employees by age

## Key Findings

- SELECT is used to retrieve data from a table.
- WHERE is used to filter records based on conditions.
- ORDER BY is used to sort query results.
- ASC sorts data from lowest to highest.
- DESC sorts data from highest to lowest.
